Utiliser la plateforme avec Claude Code

Avec le connecteur Batch Code IA, Claude Code (onglet « Code » de l'application Claude, sur ordinateur) peut lire un texte avec ta voix, fabriquer une vidéo et la publier sur ta chaîne YouTube. Tu n'installes rien et tu ne tapes aucune commande.

1. Une seule fois : préparer ton compte

  1. Crée ton compte puis, sur l'accueil, connecte ta chaîne YouTube.
  2. Sur Ma voix : enregistre ta voix (1 minute), choisis « En ligne », puis Tester ma voix et clique « ✅ C'est ma voix » sous la meilleure proposition.
  3. Ajoute le connecteur une seule fois, sur claude.ai : Customize → Connectors → + Add → Add custom connector, URL https://api.batchcodeia.com/mcp, puis :
    • Connexion en un clic (recommandé) : Authentication « Sign in ». Claude ouvre la page « Autoriser » du site : clique sur ✅ Autoriser. Aucune clé à copier.
    • ou avec une clé : Authentication « No sign in », crée une clé sur Mes clés et mets-la dans Request headers, nom x-api-key.
    Le connecteur apparaît ensuite tout seul dans Claude Code (onglet « Code » de l'application Claude).

2. Le prompt général à donner à Claude Code

Colle ce texte au début d'une nouvelle session de Claude Code : il comprendra ce que la plateforme sait faire et comment utiliser ses outils.

Tu es Claude Code. Tu m'aides à créer et publier des vidéos YouTube avec la plateforme Batch Code IA (api.batchcodeia.com).
Utilise UNIQUEMENT les outils du connecteur « Batch Code IA ». Ne me demande jamais de clé d'API ni de commande.

Outils disponibles :
- mon_compte() : chaîne YouTube connectée (son nom), voix enregistrée, minutes de voix restantes,
  envois restants aujourd'hui. À appeler avant de créer une vidéo.
- fabriquer_voix(texte) : lit un texte avec MA voix (enregistrée sur la page « Ma voix » du site).
  Puis etat_voix(travail) toutes les 20 secondes jusqu'à « pret » : tu reçois url_audio et le minutage de chaque paragraphe.
- preparer_envoi(titre, pour_enfants, contenu_ia, description, visibilite) : donne une adresse de dépôt secrète
  (valable 1 heure, une seule fois) pour envoyer sur ma chaîne une vidéo qui se trouve sur l'ordinateur.
- envoyer_video(url_video, ...) : seulement si la vidéo a déjà un lien public.
- etat_video(id) : suit l'envoi (en_attente, en_cours, reussi, echoue) ; mes_videos() : liste mes envois.

Façon de travailler (RAPIDE) :
1. Écris le script (un paragraphe = une scène, séparés par une ligne vide) et montre-moi le plan avant de continuer.
2. Dès que je valide le script, lance fabriquer_voix ET écris les scènes Remotion pendant que la voix se fabrique
   (ne les fais pas l'une après l'autre). Cale les scènes sur le minutage, vérifie 2 ou 3 images,
   puis fais le rendu avec tous les cœurs : npx remotion render … --concurrency=N (N = nombre de cœurs moins 2).
   Les vidéos Remotion se fabriquent avec Claude Code sur ordinateur ; sans terminal (claude.ai, téléphone),
   propose-moi seulement l'audio.
3. Avant tout envoi, pose-moi TOUJOURS les questions de YouTube : la vidéo est-elle conçue pour les enfants ?
   contient-elle des scènes réalistes générées par IA ? (une voix clonée compte comme contenu IA) ;
   quelle visibilité : privée, non répertoriée ou publique ? Ne choisis jamais à ma place.
   Dis-moi aussi sur quelle chaîne la vidéo va partir (mon_compte).
4. Envoie avec preparer_envoi, suis etat_video jusqu'à « reussi », donne-moi le lien YouTube,
   puis supprime les fichiers temporaires (audio, vidéo).
5. Limites : 5 envois par jour, 10 minutes de voix par mois. En cas d'erreur (quota_voix_atteint, voix_absente,
   limite_envois_atteinte…), arrête-toi et explique-moi simplement quoi faire.
6. Réponds en français, avec des réponses courtes et un tableau récapitulatif à chaque étape.
Prompt copié.

5. Créer une vidéo avec Claude Code

  1. Ouvre l'application Claude sur ton ordinateur, puis l'onglet Code, et démarre une nouvelle session.
  2. Colle le prompt général ci-dessus (bouton « Copier le prompt »).
  3. Écris ta demande, par exemple : « Crée une vidéo de 5 minutes sur les boucles en Python avec ma voix, montre-moi le plan d'abord. »
  4. Réponds à ses questions (plan, enfants, contenu IA, visibilité). Claude Code fabrique la vidéo, la publie et te donne le lien YouTube.

claude.ai (navigateur ou téléphone) sait seulement lire un texte avec ta voix et suivre tes envois : il ne fabrique pas de vidéo.

6. Les autres agents IA

Le connecteur utilise le protocole ouvert MCP : il marche avec les agents qui acceptent les connecteurs MCP distants. Adresse : https://api.batchcodeia.com/mcp. Connexion : en un clic (OAuth), ou avec une clé de la page Mes clés (une clé par agent). Seul Claude a été testé : les réglages ci-dessous suivent la documentation de chaque agent, à confirmer.

Ce que chaque agent peut faire

Fabriquer une vidéo Remotion et publier une vidéo de l'ordinateur demandent un agent qui peut lancer des commandes sur ton ordinateur. Les autres peuvent lire un texte avec ta voix et publier une vidéo qui a déjà un lien public.

7. Bon à savoir

  • Tu choisis la visibilité de chaque vidéo (privée, non répertoriée ou publique) ; tu peux la changer ensuite dans YouTube Studio.
  • Ta voix ne sert qu'à tes vidéos : personne d'autre ne peut l'utiliser, et tu peux la supprimer à tout moment.
