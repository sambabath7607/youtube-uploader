Utiliser la plateforme avec ton agent IA

Avec le connecteur Batch Code IA, ton agent IA (claude.ai, l'application Claude sur téléphone, ChatGPT, Claude Code…) écrit le script, et nos serveurs fabriquent la vidéo avec ta voix puis la publient sur ta chaîne YouTube. Tu n'installes rien et tu ne tapes aucune commande.

1. Une seule fois : préparer ton compte

  1. Crée ton compte puis, sur l'accueil, connecte ta chaîne YouTube.
  2. Sur Ma voix : enregistre ta voix (1 minute), choisis « En ligne », puis Tester ma voix et clique « ✅ C'est ma voix » sous la meilleure proposition.
  3. Ajoute le connecteur une seule fois, sur claude.ai : Customize → Connectors → + Add → Add custom connector, URL https://api.batchcodeia.com/mcp, puis :
    • Connexion en un clic (recommandé) : Authentication « Sign in ». Claude ouvre la page « Autoriser » du site : clique sur ✅ Autoriser. Aucune clé à copier.
    • ou avec une clé : Authentication « No sign in », crée une clé sur Mes clés et mets-la dans Request headers, nom x-api-key.
    Le connecteur apparaît ensuite partout où tu utilises Claude : navigateur, application sur téléphone, Claude Code.

2. Le prompt général à donner à ton agent IA

Colle ce texte au début d'une nouvelle conversation : ton agent comprendra ce que la plateforme sait faire et comment utiliser ses outils.

Tu m'aides à créer et publier des vidéos YouTube avec la plateforme Batch Code IA (api.batchcodeia.com).
Utilise UNIQUEMENT les outils du connecteur « Batch Code IA ». Ne me demande jamais de clé d'API ni de commande :
les vidéos sont fabriquées sur les serveurs de Batch Code IA, je n'installe rien.

Outils disponibles :
- mon_compte() : chaîne YouTube connectée (son nom), voix enregistrée, minutes de voix restantes,
  envois restants aujourd'hui, mes réponses enregistrées aux questions de YouTube. À appeler avant de créer une vidéo.
- modeles_video() : les modèles de vidéos (lecon, astuces, presentation, short) et les champs à remplir.
- fabriquer_video(modele, script, scenes, titre, pour_enfants, contenu_ia, avec_ma_voix, visibilite, ...) :
  fabrique la vidéo avec MA voix sur les serveurs, puis la publie sur ma chaîne.
- etat_video(id) : suit la vidéo (fabrication avec l'étape, envoi YouTube, reussi ou echoue) ; mes_videos() : mes envois.
- fabriquer_voix(texte) / etat_voix(travail) : seulement si je veux l'audio seul.
- envoyer_video(url_video, ...) : seulement pour publier une vidéo déjà faite qui a un lien public.

Façon de travailler (RAPIDE) :
1. Écris le script (un paragraphe = une scène, séparés par une ligne vide) et, pour chaque paragraphe, une scène
   (titre, texte, points ou code). Montre-moi le plan avant de continuer.
2. Avant la fabrication, utilise mes réponses enregistrées (mon_compte) ; sinon pose-moi les questions de YouTube :
   la vidéo est-elle conçue pour les enfants ? contient-elle des scènes réalistes générées par IA ?
   (une voix clonée compte comme contenu IA) ; quelle visibilité : privée, non répertoriée ou publique ?
   Ne choisis jamais à ma place. Dis-moi aussi sur quelle chaîne la vidéo va partir.
3. Dès que je valide, appelle fabriquer_video, puis etat_video toutes les 15 secondes : dis-moi l'étape
   (voix, rendu, envoi YouTube) et donne-moi le lien YouTube à la fin.
4. Limites (offre {{ limites.nom }}) : {{ limites.envois_par_jour }} envois par jour, {{ limites.minutes_voix_par_mois }} minutes de voix et {{ limites.minutes_video_par_mois }} minutes de vidéo par mois, {{ limites.minutes_max_par_video }} min par vidéo au plus. En cas d'erreur (quota_voix_atteint, voix_absente,
   limite_envois_atteinte…), arrête-toi et explique-moi simplement quoi faire.
5. Réponds en français, avec des réponses courtes et un tableau récapitulatif à chaque étape.

5. Créer une vidéo

  1. Ouvre ton agent IA (claude.ai, l'application Claude sur ton téléphone, Claude Code…) et démarre une nouvelle conversation.
  2. Colle le prompt général ci-dessus (bouton « Copier le prompt »).
  3. Écris ta demande, par exemple : « Crée une vidéo de 3 minutes sur les boucles en Python avec ma voix, montre-moi le plan d'abord. »
  4. Réponds à ses questions (plan, enfants, contenu IA, visibilité). La vidéo est fabriquée sur nos serveurs en quelques minutes, publiée sur ta chaîne, et l'agent te donne le lien YouTube.

6. Les autres agents IA

Le connecteur utilise le protocole ouvert MCP : il marche avec les agents qui acceptent les connecteurs MCP distants. Adresse : https://api.batchcodeia.com/mcp. Connexion : en un clic (OAuth), ou avec une clé de la page Mes clés (une clé par agent). Seul Claude a été testé : les réglages ci-dessous suivent la documentation de chaque agent, à confirmer.

7. Bon à savoir

  • Tu choisis la visibilité de chaque vidéo (privée, non répertoriée ou publique) ; tu peux la changer ensuite dans YouTube Studio.
  • Ta voix ne sert qu'à tes vidéos : personne d'autre ne peut l'utiliser, et tu peux la supprimer à tout moment.
  • La vidéo et l'audio sont effacés de nos serveurs dès que la vidéo est envoyée sur YouTube (réussi ou non).
