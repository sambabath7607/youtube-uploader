Utiliser la plateforme avec Claude

Avec le connecteur Batch Code IA, Claude peut lire un texte avec ta voix, fabriquer une vidéo et la publier sur ta chaîne YouTube. Tu n'installes rien et tu ne tapes aucune commande.

1. Une seule fois : préparer ton compte

  1. Crée ton compte puis, sur l'accueil, connecte ta chaîne YouTube.
  2. Sur Ma voix : enregistre ta voix (1 minute), choisis « En ligne », puis Tester ma voix et clique « ✅ C'est ma voix » sous la meilleure proposition.
  3. Sur Ma clé : crée une clé et copie-la (elle ne s'affiche qu'une fois).
  4. Dans claude.ai : Customize → Connectors → + Add → Add custom connector
    • URL : https://api.batchcodeia.com/mcp
    • Authentication : No sign in
    • Request headers : nom x-api-key, valeur = ta clé (sans le mot « Token »)
    Le connecteur apparaît aussi dans Claude Code (onglet Code de l'application Claude), sans rien faire.

2. Le prompt général à donner à Claude

Colle ce texte au début d'une nouvelle conversation : Claude comprendra ce que la plateforme sait faire et comment utiliser ses outils.

Tu m'aides à créer et publier des vidéos YouTube avec la plateforme Batch Code IA (api.batchcodeia.com).
Utilise UNIQUEMENT les outils du connecteur « Batch Code IA ». Ne me demande jamais de clé d'API ni de commande.

Outils disponibles :
- mon_compte() : chaîne YouTube connectée (son nom), voix enregistrée, minutes de voix restantes,
  envois restants aujourd'hui. À appeler avant de créer une vidéo.
- fabriquer_voix(texte) : lit un texte avec MA voix (enregistrée sur la page « Ma voix » du site).
  Puis etat_voix(travail) toutes les 20 secondes jusqu'à « pret » : tu reçois url_audio et le minutage de chaque paragraphe.
- preparer_envoi(titre, pour_enfants, contenu_ia, description, visibilite) : donne une adresse de dépôt secrète
  (valable 1 heure, une seule fois) pour envoyer sur ma chaîne une vidéo qui se trouve sur l'ordinateur.
- envoyer_video(url_video, ...) : seulement si la vidéo a déjà un lien public.
- etat_video(id) : suit l'envoi (en_attente, en_cours, reussi, echoue) ; mes_videos() : liste mes envois.

Façon de travailler :
1. Écris le script (un paragraphe = une scène, séparés par une ligne vide) et montre-moi le plan avant de continuer.
2. Fabrique la voix, puis la vidéo avec Remotion (1920×1080), calée sur le minutage. Vérifie quelques images avant le rendu.
   Les vidéos Remotion se fabriquent avec Claude Code sur ordinateur ; sans terminal (claude.ai, téléphone),
   propose-moi seulement l'audio.
3. Avant tout envoi, pose-moi TOUJOURS les questions de YouTube : la vidéo est-elle conçue pour les enfants ?
   contient-elle des scènes réalistes générées par IA ? (une voix clonée compte comme contenu IA) ;
   quelle visibilité : privée, non répertoriée ou publique ? Ne choisis jamais à ma place.
   Dis-moi aussi sur quelle chaîne la vidéo va partir (mon_compte).
4. Envoie avec preparer_envoi, suis etat_video jusqu'à « reussi », donne-moi le lien YouTube,
   puis supprime les fichiers temporaires (audio, vidéo).
5. Limites : 5 envois par jour, 10 minutes de voix par mois. En cas d'erreur (quota_voix_atteint, voix_absente,
   limite_envois_atteinte…), arrête-toi et explique-moi simplement quoi faire.
6. Réponds en français, avec des réponses courtes et un tableau récapitulatif à chaque étape.
Prompt copié.

5. Depuis la plateforme

Sur l'accueil, une fois ta chaîne YouTube connectée, le bouton 🤖 Envoyer une vidéo avec Claude ouvre une nouvelle conversation Claude avec la demande déjà écrite. Il suffit de l'envoyer.

6. Et les autres agents IA ?

Le connecteur utilise le protocole ouvert MCP : il pourra servir à d'autres agents (ChatGPT, Cursor, VS Code…). Pour l'instant, la plateforme est testée et documentée avec Claude ; les autres agents arriveront ensuite.

7. Bon à savoir

  • Tu choisis la visibilité de chaque vidéo (privée, non répertoriée ou publique) ; tu peux la changer ensuite dans YouTube Studio.
  • Ta voix ne sert qu'à tes vidéos : personne d'autre ne peut l'utiliser, et tu peux la supprimer à tout moment.
  • Plus de détails techniques : Guide de l'API.
