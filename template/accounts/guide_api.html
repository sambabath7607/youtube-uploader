Guide de l'API YouTube Uploader

Cette API permet d'envoyer des vidéos sur ta propre chaîne YouTube depuis un terminal ou avec Claude Code, sans passer par le site.

1. Créer ton compte

  1. Inscris-toi sur le site.
  2. Sur l'accueil, clique sur « Connecter ma chaîne YouTube » et accepte l'accès demandé par Google.

2. Récupérer ta clé d'API

Va sur la page « Ma clé d'API » et copie ta clé. Elle prouve à l'API que c'est bien toi. Ne la partage jamais. Si elle a fuité, clique sur « Régénérer ».

Sous Windows, enregistre-la une seule fois, puis ouvre un nouveau terminal :

setx YOUTUBE_API_KEY "TA_CLE"

3. Envoyer une vidéo

curl.exe -X POST https://api.batchcodeia.com/youtube/api/v1/videos/ -H "Authorization: Token TA_CLE" -F "fichier=@video.mp4" -F "titre=Ma vidéo" -F "pour_enfants=false" -F "contenu_ia=false"
  • fichier : ta vidéo (obligatoire).
  • titre : le titre sur YouTube (obligatoire).
  • pour_enfants : true ou false (obligatoire, c'est une règle de YouTube).
  • contenu_ia : true si la vidéo contient des scènes réalistes générées ou modifiées par IA, sinon false.

L'API répond tout de suite avec le code 202 et un numéro de vidéo. L'envoi vers YouTube continue en arrière-plan.

4. Suivre l'état de l'envoi

curl.exe https://api.batchcodeia.com/youtube/api/v1/videos/NUMERO/ -H "Authorization: Token TA_CLE"

Le champ « etat » indique où en est l'envoi. Si l'envoi échoue, le champ « erreur » explique pourquoi.

5. Voir la liste de tes vidéos

curl.exe https://api.batchcodeia.com/youtube/api/v1/videos/ -H "Authorization: Token TA_CLE"

La liste affiche 20 vidéos par page. Ajoute ?page=2 à l'adresse pour voir la suite.

6. Utiliser Claude Code

Ouvre Claude Code dans le dossier du projet et demande-lui d'envoyer ta vidéo. Il te posera les questions obligatoires, comme le titre et « pour enfants », avant chaque envoi.

Limites

  • Formats acceptés : mp4, mov, webm.
  • Taille maximale : 500 Mo.
  • 5 envois par jour et par compte.
  • 60 requêtes par minute.
  • YouTube a aussi sa propre limite d'envois par jour.

Erreurs possibles

Chaque erreur répond au format : {"erreur": "message", "code": "nom_court"}.

  • 400 : un champ manque ou il est invalide, ou ta chaîne n'est pas connectée.
  • 401 : clé d'API absente ou fausse.
  • 404 : vidéo introuvable.
  • 405 : mauvaise méthode, GET au lieu de POST par exemple.
  • 429 : trop de requêtes, ou limite d'envois du jour atteinte.

Tes données

Tu peux à tout moment déconnecter ta chaîne, télécharger tes données ou supprimer ton compte depuis l'accueil.
