Guide de l'API YouTube Uploader

Cette API permet de fabriquer des vidéos sur nos serveurs et de les envoyer sur ta propre chaîne YouTube, sans passer par le site. Le plus simple reste le connecteur pour ton agent IA : Utiliser avec ton agent IA.

1. Créer ton compte

  1. Inscris-toi sur le site.
  2. Sur l'accueil, clique sur « Connecter ma chaîne YouTube » et accepte l'accès demandé par Google.

2. Récupérer ta clé d'API

Va sur la page « Ma clé d'API », clique sur « Créer une nouvelle clé » et copie-la tout de suite : pour ta sécurité, elle n'est affichée qu'une seule fois. Elle prouve à l'API que c'est bien toi. Ne la partage jamais. Si elle a fuité ou si tu l'as perdue, crée une nouvelle clé.

Sous Windows, enregistre-la une seule fois, puis ouvre un nouveau terminal :

setx YOUTUBE_API_KEY "TA_CLE"

3. Envoyer une vidéo

curl.exe -X POST https://api.batchcodeia.com/youtube/api/v1/videos/ -H "Authorization: Token TA_CLE" -F "fichier=@video.mp4" -F "titre=Ma vidéo" -F "pour_enfants=false" -F "contenu_ia=false"
  • fichier : ta vidéo (obligatoire).
  • titre : le titre sur YouTube (obligatoire).
  • pour_enfants : true ou false (obligatoire, c'est une règle de YouTube).
  • contenu_ia : true si la vidéo contient des scènes réalistes générées ou modifiées par IA, sinon false.

L'API répond tout de suite avec le code 202 et un numéro de vidéo. L'envoi vers YouTube continue en arrière-plan.

3 bis. Fabriquer une vidéo sur nos serveurs (sans fichier)

Tu envoies seulement le script et les scènes d'un modèle : la voix, l'animation et le montage sont faits sur nos serveurs, puis la vidéo part sur ta chaîne.

curl.exe -X POST https://api.batchcodeia.com/youtube/api/v1/fabrications/ -H "Authorization: Token TA_CLE" -H "Content-Type: application/json" -d "{\"modele\": \"lecon\", \"titre\": \"Les listes en Python\", \"script\": \"Les listes en Python.\n\nUne liste est modifiable.\", \"scenes\": [{\"type\": \"titre\", \"texte\": \"Les listes\"}, {\"type\": \"texte\", \"texte\": \"Une liste est modifiable\"}], \"pour_enfants\": false, \"contenu_ia\": true, \"avec_ma_voix\": true}"
  • modele : lecon, astuces, presentation ou short (obligatoire). Liste et champs : GET /youtube/api/v1/modeles/.
  • script : le texte lu par la voix ; un paragraphe (séparé par une ligne vide) = une scène.
  • scenes : une scène par paragraphe : type (titre, texte, points, code, fin), texte, points, code, langage.
  • titre, pour_enfants, contenu_ia : obligatoires (avec ta voix, contenu_ia vaut toujours true).
  • avec_ma_voix (true par défaut), visibilite, description, accent (#RRGGBB), musique (calme, energique, aucune) : facultatifs.

Réponse 202 avec un numéro de vidéo et « etat » : « fabrication ». Suis-la comme un envoi (étape suivante) : le champ « etape » dit où en est la fabrication (voix, rendu 7/12, assemblage), puis l'envoi YouTube démarre tout seul. Erreurs propres à la fabrication : 400 video_trop_longue, 400 voix_absente, 409 fabrication_en_cours (une à la fois), 429 quota_voix_atteint, 429 quota_video_atteint ou duree_max_atteinte (limites de l'offre), 503 service_video_indisponible, 503 capacite_service_atteinte (capacité du mois du service atteinte : réessaie plus tard).

4. Suivre l'état de l'envoi

curl.exe https://api.batchcodeia.com/youtube/api/v1/videos/NUMERO/ -H "Authorization: Token TA_CLE"

Le champ « etat » indique où en est la vidéo : fabrication, fabrication_echouee, en_attente, en_cours, reussi ou echoue. Si quelque chose échoue, le champ « erreur » explique pourquoi.

5. Voir la liste de tes vidéos

curl.exe https://api.batchcodeia.com/youtube/api/v1/videos/ -H "Authorization: Token TA_CLE"

La liste affiche 20 vidéos par page. Ajoute ?page=2 à l'adresse pour voir la suite.

6. Pour les développeurs : déposer un fichier en deux temps

POST /youtube/api/v1/envois/ (mêmes champs que l'envoi, sans le fichier) réserve un envoi et renvoie une adresse de dépôt secrète, valable 1 heure et utilisable une seule fois : curl -F "fichier=@video.mp4" "ADRESSE". Cette route sert aux scripts des développeurs ; les agents IA utilisent la fabrication sur nos serveurs.

Limites

  • Formats acceptés : mp4, mov, webm.
  • Taille maximale : 500 Mo.
  • Offre {{ limites.nom }} : {{ limites.envois_par_jour }} envois par jour et par compte (une fabrication échouée ne compte pas), {{ limites.minutes_voix_par_mois }} minutes de voix et {{ limites.minutes_video_par_mois }} minutes de vidéo par mois (voir les offres).
  • Une vidéo en fabrication à la fois ; durée maximale : {{ limites.minutes_max_par_video }} min avec ton offre, et selon le modèle (60 secondes pour un Short).
  • 60 requêtes par minute.
  • YouTube a aussi sa propre limite d'envois par jour.

Erreurs possibles

Chaque erreur répond au format : {"erreur": "message", "code": "nom_court"}.

  • 400 : un champ manque ou il est invalide, ou ta chaîne n'est pas connectée.
  • 401 : clé d'API absente ou fausse.
  • 404 : vidéo introuvable.
  • 405 : mauvaise méthode, GET au lieu de POST par exemple.
  • 409 : vidéo déjà en cours (même titre) ou déjà en fabrication.
  • 429 : trop de requêtes, limite d'envois du jour atteinte (la tienne ou celle du service), ou quota de voix atteint.
  • 503 : service de fabrication momentanément indisponible, ou capacité du mois atteinte.

Tes données

Tu peux à tout moment déconnecter ta chaîne, télécharger tes données ou supprimer ton compte depuis l'accueil.
